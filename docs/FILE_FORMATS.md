# File Formats

> All records generated by this project are completely synthetic. Real public data is used only for sourced parameters and seeds. See [SYNTHETIC_DATA_NOTICE.md](../SYNTHETIC_DATA_NOTICE.md).

This document describes the file formats the detection engine reads from a manufacturer's inbox. Each section gives the format's purpose, the key fields the engine uses, and a link to the public specification or guidance it follows.

## EDI X12 004010 transaction sets

The Electronic Data Interchange (EDI) files use the ASC X12 004010 format. Three transaction sets make up the wholesaler purchase channel.

### 844 - Product Transfer Account Adjustment (chargeback)

The wholesaler sends an 844 when a covered entity or contract pharmacy orders a drug at the 340B contract price. The 844 asks the manufacturer to credit the difference between the Wholesale Acquisition Cost (WAC) and the contract price.

**Layout source:** Cencora (AmerisourceBergen), Supplier Outbound 844 Specification, V4010, June 2023 ([PDF](https://www.amerisourcebergen.com/-/media/assets/amerisourcebergen/supplier_o844_4010_specification---june-2023.pdf)).

**Key segments and fields:**

| Segment | Field | Engine use |
|---|---|---|
| BAA | BAA02 (action code), BAA05 (debit memo number) | Identifies the chargeback request/ request for credit |
| CON | CON02 (contract number) | Links to the 340B contract |
| N1 (customer loop) | N103/N104 (identifier qualifier and value) | Customer name |
| REF | REF*2U (340B ID) | Identifies the covered entity's 340B registration - customer 340B reference identification|
| REF | REF*HI (HIN) | Customer Health Industry Number (when present) - customer HIN reference identificarion|
| SII | SII03 (NDC-11), SII04 (quantity), SII05 (unit price) | Drug, volume and contract price per line - sales item information|
| N9 | N902 (reference number) | Line-level identifiers - reference identification|
| AMT | AMT*CC (chargeback claim total) | Dollar amount of the credit request |

The 844 functional group identifier is CF.

### 849 - Response to Product Transfer Account Adjustment

The manufacturer returns an 849 to accept, partially accept or reject the chargeback. The Cencora layout covers the header-level (undisputed) response.

**Layout source:** Cencora, I849 for Undisputed Chargebacks V4010, March 2023 ([PDF](https://www.amerisourcebergen.com/-/media/assets/amerisourcebergen/i849_undisputed-chargebacks---june-2023.pdf)).

**Key segments and fields:**

| Segment | Field | Engine use |
|---|---|---|
| BRC | BRC01 (action code), BRC02 (reference number) | Response status (00 = accepted) |
| REF*AM | Debit memo number | Matches back to the 844 |
| CTT | CTT01 (line count) | Number of lines in error, if any |
| AMT | AMT*S (submitted), AMT*NA (not accepted), AMT*A (accepted) | Reconciliation of the credit amount |

Line-level dispute detail is not defined in the Cencora guide. The engine writes disputes as a CSV extract from the manufacturer's chargeback system. The Healthcare Distribution Alliance (HDA) EDI 849 guideline (2020) covers line-level segments but was not consulted for this project.

### 867 - Product Transfer and Resale Report

The wholesaler sends an 867 to report product shipments to each customer location. The manufacturer uses it to track which drugs were shipped to which sites.

**Layout source:** Cencora, O867 Product Transfer and Resale Report, 4121V2, June 2015 ([PDF](https://www.amerisourcebergen.com/-/media/assets/amerisourcebergen/867-product-transfer-and-resale-report-v5.pdf)).

**Key segments and fields:**

| Segment | Field | Engine use |
|---|---|---|
| BPT | BPT01 (report type code 00) | Beginning of the report |
| DTM | DTM*090, DTM*091 (report period start/end) | Date range of the shipment data |
| N1*ST | N103/N104 (ship-to DEA), N3 (address), N4 (city/state/zip) | Identifies the receiving site |
| REF*HI | Ship-to HIN | When present |
| REF*CT | Contract type | Indicates the purchasing account type |
| SII | SII01 (N4 = NDC qualifier), SII03 (NDC-11), SII04 (quantity), SII05 (unit price) | Drug, volume and WAC price per shipment line |
| N9*DI | Invoice number | Links to the wholesaler's invoice |

The 867 functional group identifier is PT.

### EDI envelope

All three transaction sets share the X12 envelope structure:

- **ISA/IEA** (interchange control header/trailer): wraps the entire file.
- **GS/GE** (functional group header/trailer): groups transaction sets by type (GS01 = CF for 844 and 849, PT for 867).
- **ST/SE** (transaction set header/trailer): wraps each individual transaction; SE01 counts all segments from ST to SE inclusive.

The engine's `x12_el` macro uses `try_element_at` to extract fields by position, returning NULL for short segments rather than failing. The `x12_date` macro converts CCYYMMDD strings to date values. The `x12_loop_number` macro counts loop boundaries using a running window.

## CMS-R-144 Medicaid rebate invoice

States send quarterly Medicaid rebate invoices to manufacturers using the CMS-R-144 form. The invoice lists each National Drug Code (NDC), the number of units dispensed to Medicaid beneficiaries, and the Unit Rebate Amount (URA) owed.

**Layout source:** CMS, CMS-R-144 State Invoice Data Definitions, July 2021 ([PDF](https://www.medicaid.gov/sites/default/files/2021-02/cms-r-144-state-invoice-data-definitions-jul-2021.pdf)).

**Key fields used by the engine:**

| Field | Description |
|---|---|
| Record ID | FFSU (fee-for-service utilization) or MCOU (managed care organization utilization) |
| State code | Two-letter state abbreviation |
| Labeler code | First segment of the NDC |
| Product code / Package size code | Second and third segments of the NDC |
| Units reimbursed | Number of units the state paid for |
| URA | Unit Rebate Amount from CMS |
| Total amount due | Units reimbursed times URA |
| Prior quarter adjustment | Corrections to a prior quarter's invoice |

States must submit invoices within 60 calendar days of the quarter's end (42 CFR 447.511). Managed care utilization (MCOU) is reported separately from fee-for-service (FFSU).

## Medicare Transaction Facilitator (MTF)

CMS operates the MTF to pass Medicare Part D claim data for drugs with a Maximum Fair Price (MFP) to manufacturers, who then calculate and pay the MFP refund (the difference between WAC and MFP). The MTF has a Data Module (claim data) and a Payment Module (refund settlement).

**Layout source:** CMS, Medicare Drug Price Negotiation Program: Final Guidance for IPAY 2028 and Manufacturer Effectuation of the MFP in 2026, 2027, and 2028, section 40.4, September 2025 ([PDF](https://www.cms.gov/files/document/medicare-drug-price-negotiation-final-guidance-ipay-2028-mfp-effectuation-2026-2028.pdf)).

**Additional guidance:** CMS, Medicare Transaction Facilitator, Pharmacies and Other Dispensing Entities FAQ, updated April 2026 ([PDF](https://www.cms.gov/files/document/medicare-transaction-facilitator-pharmacies-other-dispensing-entities-frequently-asked-questions.pdf-0)).

**Key MTF Data Module fields used by the engine:**

| Field | Description |
|---|---|
| ICN | Internal Control Number, the MTF's unique claim identifier |
| NDC-11 | 11-digit National Drug Code of the dispensed drug |
| Date of service | Date the drug was dispensed |
| Quantity | Number of units dispensed |
| Dispensing entity NPI | NPI of the pharmacy or provider that dispensed the drug |
| Prescriber NPI | NPI of the prescribing provider |
| Submission Clarification Code (SCC) | Value 20 indicates a 340B claim |
| LIS indicator | Whether the beneficiary has the Medicare Part D Low-Income Subsidy |
| WAC per unit | Wholesale Acquisition Cost on the date of service |
| MFP per unit | Applicable Maximum Fair Price |

**Key MTF Payment Module fields used by the engine:**

| Field | Description |
|---|---|
| ICN | Matches the Data Module claim |
| Refund method code | 1 = full refund, 2 = partial, other codes for adjustments and reversals |
| Refund amount | Dollar amount of the MFP refund |

The Standard Default Refund Amount (SDRA) is WAC minus MFP per unit. Manufacturers process refunds within approximately 21 days of the dispensing date. The MFP refund is subject to nonduplication with the 340B ceiling price under SSA 1193(d).

## HRSA 340B Rebate Model Pilot Program submissions

Covered entities that participate in the Pilot submit claims to the Beacon platform for each dispense of a Pilot-eligible NDC-11, regardless of payer, within 45 days of the dispensing date. The manufacturer pays or denies the rebate within 10 business days.

**Layout source:** HRSA, Notice Regarding 340B Rebate Model Pilot Program, 91 Fed. Reg. 48,883, August 3, 2026, sections VIII.B through VIII.D.

**Key Pilot submission fields used by the engine:**

| Field | Description |
|---|---|
| Covered entity 340B ID | The entity's HRSA registration identifier |
| Dispensing pharmacy NPI | NPI of the pharmacy that filled the prescription |
| Prescriber NPI | NPI of the prescribing provider |
| NDC-11 | 11-digit code of the dispensed drug |
| Quantity dispensed | Number of units |
| Date of service | Dispensing date |
| BIN | Bank Identification Number; set to 999999 for cash claims |
| PCN | Processor Control Number; set to CASH or NONE for uninsured patients |
| Rx number | Pharmacy's prescription number |
| Fill number | 0 for a new prescription, incremented for refills |
| Wasted units | Units wasted during preparation (reported separately for medical claims) |

The Pilot platform applies validations before accepting a submission: the NDC-11 must be on the manufacturer's approved plan list, the dispensing pharmacy must be registered on OPAIS as an owned or contract pharmacy of the submitting entity, and the entity type must not be excluded by the plan (some plans exclude certain hospital types). The first conforming submission for a given claim is accepted; subsequent submissions by other entities for the same fill are rejected.

Manufacturers may not deny a rebate for diversion, Medicaid duplicate discounts, eligibility questions, or the absence of confirmed WAC purchases. They may deny for MFP nonduplication (when the MFP is lower than the 340B ceiling price) or when the same claim has already received a rebate from another entity.

For details on the approved manufacturer plans, see the HRSA Pilot program page ([hrsa.gov/opa/340b-model-pilot-program](https://www.hrsa.gov/opa/340b-model-pilot-program)).
