# Acronyms and Terms

> All records generated by this project are synthetic. Real public data is used only for sourced parameters and seeds. See [SYNTHETIC_DATA_NOTICE.md](../SYNTHETIC_DATA_NOTICE.md).

Every acronym used in the code, the documents and the published material. When a new one appears, it is added here in the same change.

| Acronym | Meaning |
|---|---|

| Acronym | Meaning |
|---|---|

## Project terms

| Term | Meaning |
|---|---|
| FWA | Fraud, waste and abuse |
| C1 / C2 | The two 340B eligibility conditions from Martin and Illich (2022): prescription written at a covered entity / filled at an owned or contracted pharmacy |
| Ground truth | The generator's record of which units really are duplicates; read only by the evaluation step |
| Two worlds | The generator knows everything; the engine sees only what a manufacturer receives |
| Carve-in / carve-out | A covered entity uses (carve-in) or does not use (carve-out) 340B drugs for Medicaid patients |
| Penny pricing | 340B ceiling price set at $0.01 when AMP minus URA is zero or less |

## Added with the conversion module

| Acronym | Meaning |
|---|---|

|---|---|
